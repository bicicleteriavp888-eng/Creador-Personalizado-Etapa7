# Skill — Renovación de interfaz de Creador Personalizado

Este paquete contiene una guía portable para continuar con otra IA la renovación visual y estructural de Creador Personalizado.

## Archivos

- `SKILL.md`: instrucciones completas, contexto del proyecto, decisiones visuales, reglas de arquitectura, etapas y criterios de aceptación.

## Cómo utilizarlo

1. Adjuntar este ZIP a la IA con la que se continuará el trabajo.
2. Adjuntar también el código fuente `Creador-Personalizado-3.0.0-alpha2-gestor-software.zip`.
3. Pedir que lea `SKILL.md` completo.
4. Comenzar por la Etapa 0 (auditoría y línea base). No autorizar cambios de código hasta revisar y aprobar el diagnóstico.

El Skill define una renovación de interfaz con Python/PySide6 y preservación de la lógica existente. No contiene el código fuente de la aplicación.
